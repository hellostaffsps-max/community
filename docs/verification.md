## إتاحة الدومين بعد اعتماد المالك

- أُتيح `https://goatlab.my` بربطه مباشرة بـWorker `community`. أُزيل سجل الجذر السابق `A 2.57.91.91` ضمن الاستبدال المعتمد، وبقي `www` سجل CNAME إلى الجذر مع Proxy وTTL Auto.
- حُفظت قاعدة Cloudflare `community canonical HTTPS`؛ أثبتت طلبات HTTP الفعلية أن `https://www.goatlab.my` و`http://www.goatlab.my` و`http://goatlab.my` تعيد 301 إلى HTTPS على الجذر، مع حفظ المسار ومعاملات الرابط.
- حُفظ Site URL في Supabase على `https://goatlab.my` وأُضيف `https://goatlab.my/auth/callback` إلى Redirect URLs، ثم تحققنا من القيم المحفوظة.
- الصفحة الرئيسية السحابية تعيد HTTP 200 وتعرض المجتمع العربي مع `Cache-Control: private, no-store`. ملف CSS يعيد 200 بنوع صحيح.
- صفحة التسجيل تعرض الإغلاق؛ طلب إنشاء الحسابات يعيد 503، وكتابة الزائر 401، والطلب من Origin خارجي 403، ومسار الصورة غير الصالح 400. صفحة الحساب تحوّل الزائر إلى تسجيل الدخول. callback بلا رمز يعيد 303 إلى صفحة الدخول على الدومين الصحيح.
- إعدادات Supabase الحية ما زالت `disable_signup=true` و`external.google=false`، وAuth وData API يعيدان 200. لم يُفتح التسجيل ولم يُعد SMTP أو Google ولم يحدث شراء.
- أُضيف الدومين إلى `cloudflare.config.ts` لضمان استمرار الربط مع النشر الآلي من GitHub. اختبار TypeScript ناجح. آخر بناء قبل هذا التغيير للنسخة `cdc0ae4` نجح خلال 56 ثانية (`bd654952-0216-4cd1-9252-737a7a8c0ec1`، إصدار `62009893`).

النتائج أدناه توثق المراحل السابقة، بما فيها الحالة قبل الموافقة على النشر العام.

## ما لم يُثبت في مرحلة التنفيذ الأولى (سجل تاريخي)

لم تُختبر رحلة مستخدم حقيقي من رسالة التأكيد إلى إعادة تعيين كلمة المرور. PGlite يختبر PostgreSQL الحقيقي وRLS لكن جداول Auth وStorage فيه بدائل اختبارية، وليس خدمات GoTrue/PostgREST/Storage الفعلية. لا توجد تجربة استعادة نسخة سحابية. نجح رفع Worker في Cloudflare بلا عنوان عام (`No targets deployed`)، لذلك لم يُختبر HTTP على النسخة السحابية. البريد مؤجل والتسجيل مغلق بطلب المالك. يجب تحديث هذا التقرير عند نجاح الاختبارات المتبقية بدل افتراض نتائجها.
